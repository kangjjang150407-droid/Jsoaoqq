# ⚔️ 볼파이트 시뮬레이터

무기를 든 공들이 경기장 안에서 튕겨 다니며 싸우는 전투 시뮬레이션입니다.
`index.html` 파일 하나로 동작하고 설치할 것이 없습니다. 모바일 세로 화면(9:16)에 맞춰져 있습니다.

## 실행 방법
- **PC**: `index.html`을 브라우저로 열기
- **휴대폰**: GitHub 저장소 → Settings → Pages → Branch 선택 후 Save → 생성된 주소로 접속
  (홈 화면에 추가하면 앱처럼 전체 화면으로 쓸 수 있어요)

## 파이터
| 종류 | 특징 |
|---|---|
| 🗡️ 검 | 맞출 때마다 피해 +1 |
| 🔱 창 | 맞출 때마다 길이 +12, 피해 +0.5 |
| 🔪 쌍단검 | 양쪽 단검, 맞출 때마다 회전 속도 증가 (6회마다 피해 +1) |
| 🔨 망치 | 느리지만 한 방 피해 5, 맞출 때마다 회전 증가 |
| 🏹 활 | 원거리 사격, 적중할 때마다 화살 수 +1 |
| 👊 맨몸 | 몸통 박치기, 맞출 때마다 속도·피해 증가 |
| 🧪 독 | 중독시켜 지속 피해, 맞출 때마다 독 강화 |

- 무기끼리 부딪히면 **패링**(튕겨내며 회전 방향 반전), 화살은 무기에 막힙니다.
- 2~4명 대전, 체력, 게임 속도, 중력 모드 설정 가능

## 🎥 영상 녹화
- **자동 녹화**: 체크해 두면 전투 시작부터 승리 3초 후까지 자동 녹화
- **수동 녹화**: 오른쪽 위 ⏺ 버튼으로 시작/정지
- 효과음 포함, 가능한 경우 **MP4**로 저장 (안 되면 WebM)
- 녹화가 끝나면 미리보기 창에서
  - iPhone: **저장/공유 → "비디오 저장"** → 사진 앱
  - Android: **저장/공유** 또는 **파일 다운로드**
- 화면의 버튼과 메뉴는 영상에 찍히지 않고 경기 화면만 녹화됩니다.
- 지원: 최신 Chrome / Edge / Samsung Internet, iOS Safari 14.5 이상
