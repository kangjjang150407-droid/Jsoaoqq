# ⚔️ 볼파이트 샌드박스

캐릭터와 VFX를 직접 만들어서 공끼리 싸움을 붙이는 전투 시뮬레이터입니다.
`index.html` 파일 하나로 동작하고, 모바일 세로 화면(9:16)에 맞춰져 있습니다.
**기본 캐릭터는 없습니다.** 처음엔 🧍 캐릭터 탭에서 직접 만들어 주세요.

## 실행 방법
- **PC**: `index.html`을 브라우저로 열기
- **휴대폰**: GitHub 저장소 → Settings → Pages에서 배포한 뒤 그 주소로 접속 (홈 화면에 추가 추천)

## 🧍 캐릭터 샌드박스
허수아비 상대로 실시간 미리보기를 보면서 편집할 수 있어요.

| 공격 종류 | 방식 | 특징 |
|---|---|---|
| ⚔️ **물리** | 근접 무기 (검/창/망치/도끼/봉), 원거리 투사체, 몸통 박치기 | 상대 **물리 방어**로 피해 감소 · 근접 무기끼리 패링 · 물리 투사체는 무기에 막힘 |
| ✦ **마법** | 마법탄 (조준/유도/튕김), 마법 파동 (범위), 회전 마법 구체 | 상대 **마법 저항**으로 피해 감소 · 무기로 막을 수 없음 |

- 프로필 이미지: 사진을 올리면 볼 안에 원형으로 표시 (확대·위치 조절, 체력 표시 위치: 가운데/아래/숨김)
- 능력치: 체력, 크기, 속도, 무게, 피해, 넉백, 무기 길이와 개수, 회전, 발사 간격, 투사체 수·속도·크기, 퍼짐, 유도, 벽 튕김, 파동 범위
- 방어: 물리 방어 %, 마법 저항 %
- 성장: 적중할 때마다 피해 / 길이 / 회전 / 속도 / 개수 / 공격 속도 / 크기 / 범위 / 체력 흡수 중 하나가 증가
- 대사: 전투 시작, 공격 적중, 피격, 승리, 사망 때 말풍선 (여러 줄을 쓰면 랜덤으로 하나, 말할 확률 설정)
- VFX: 타격, 발사, 꼬리, 사망 이펙트를 직접 만든 VFX로 지정

## ✨ VFX 샌드박스
모양(사각형/원/불꽃선/별/고리/글자·이모지), 시작·끝 색, 개수, 속도, 퍼짐 각도, 지속 시간,
크기 변화, 중력, 감속, 빛 번짐, 충격파 고리, 화면 번쩍, 화면 흔들림, 소리를 설정할 수 있어요.
미리보기 화면을 탭하면 그 자리에서 재생됩니다.

## 🤖 AI 생성
⚔️ 전투 탭 아래 **🤖 AI 설정**에 API 키를 넣으면 사용할 수 있어요. (키는 그 기기 브라우저에만 저장되고 저장소에는 올라가지 않아요)
- `sk-ant-…` 키는 Claude, 그 외 `sk-…` 키는 OpenAI 호환 API로 자동 인식 (API 주소·모델 변경 가능)
- **AI 자동 대결**: 테마만 쓰면(비워도 됨) 캐릭터 2명 + VFX + 대사를 만들어 바로 전투·녹화
- **AI로 캐릭터 만들기**: 설명 한 줄 → 능력치, 공격 방식, 색, 대사, 전용 VFX(타격/발사/꼬리/사망)까지 생성
- **AI로 VFX 만들기**: "보라색 번개 폭발" 같은 설명 → 파티클 이펙트 생성
- 편집 화면의 **AI로 수정**: "더 빠르게", "파란색으로" 같은 요청으로 현재 값을 고쳐줌
- AI가 준 값은 허용 범위로 자동 보정돼요

## 💾 저장
- 캐릭터와 VFX는 브라우저(localStorage)에 자동 저장
- 전투 탭의 **내보내기 / 가져오기**로 JSON 파일 백업이나 다른 기기로 옮기기

## 🎥 영상 녹화
- 자동 녹화: 전투 시작부터 승리 후 3.5초까지 / 수동: 오른쪽 위 ⏺ 버튼
- 효과음 포함, 가능하면 MP4로 저장 (안 되면 WebM). 버튼과 메뉴는 영상에 찍히지 않아요
- iPhone: 저장/공유 → "비디오 저장" / Android: 저장/공유 또는 파일 다운로드
